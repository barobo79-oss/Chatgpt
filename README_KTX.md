# 🚄 KTX 취소표 예약대기 도우미 (합법 버전)

> **한 줄 요약** — 코레일에 로그인해 좌석을 자동으로 낚아채는 '매크로'는 만들지 않았습니다.
> 대신 **공식 예약대기 안내 + 취소표가 잘 나오는 시간대 알림 + 공공데이터 열차조회**로
> "표 잡을 확률"을 합법적으로 최대한 끌어올리는 도구입니다. 예매 버튼은 사람이 누릅니다.

---

## 1. 왜 '자동 예매 매크로'가 아니라 '도우미'인가

메타문, 요청하신 대로 먼저 **코레일 현재 상태**를 조사했고, 그 결과 "가장 효과적인 방안"의
정의를 바꿔야 한다는 결론에 도달했습니다. 이유는 셋입니다.

### (1) 기술적으로 — 코레일이 매크로를 정조준해 차단하고 있습니다 (2026년)

| 항목 | 현황 |
|---|---|
| 매크로 탐지 솔루션 | 2025년 도입, **하루 평균 약 1.6만 건**의 매크로 접근을 차단 |
| 탐지 방식 | '연속 조회·반복 접속' 등 비정상 패턴을 빅데이터로 탐지 |
| 효과 | 반복 구매·취소 악용 사례가 **99% 감소** (하루 75건 → 0.8건) |
| 앱 API 보호 | 앱 요청에 위·변조 방지 서명(무결성 토큰)이 붙어, 정식 앱이 아니면 차단 |

즉, 오픈소스 매크로들이 "동작"하려면 **정식 앱인 척 위장하고 이 탐지·서명 체계를 뚫어야**
합니다. 이는 전형적인 '탐지 우회' 기술이라 제가 만들어 드릴 수 없고, 만들어도 코레일 업데이트
한 번에 막히는 소모전입니다.

### (2) 법적으로 — 개인용이라도 위험합니다

| 근거 | 내용 |
|---|---|
| 형법 업무방해죄 | 매크로로 예매 시스템·서버 운영을 방해한 것으로 보아 **개인 사용자도 수사·처벌된 사례**가 있음 |
| 철도사업법 | 영업 목적 웃돈 재판매·알선은 **최대 1,000만원 과태료** |
| 코레일 이용약관 | 자동화 프로그램 사용 시 **계정 정지·예매 제한·승차권 취소** 가능 |

### (3) 그래서 진짜 '가장 효과적인 합법 수단'은 따로 있습니다 → **공식 예약대기**

매진된 열차에 **예약대기**를 걸어 두면, 취소분이 생겼을 때 **코레일이 자동으로 배정**하고
알림톡/문자로 알려 줍니다. 사람이 밤새 새로고침할 필요가 없습니다. 이게 개인에게 가장
확실하고 안전한 방법입니다. 이 도구는 그 예약대기를 **놓치지 않게** 돕고, 예약대기가 안 되는
경우엔 **취소표가 잘 나오는 시간에 알림**을 줍니다.

---

## 2. 취소표는 언제 잘 나오나 (이 도구가 알려 주는 시간대)

```
 D-3 ────────── D-2 ────────── D-1 ────────── 출발일(D-0) ── 출발
  │              │              │              │
  ├─ 23:40  미결제 예약 자동취소 시작 (자정 전)         ← 매일 반복
  ├─ 00:15  미결제 예약 자동취소 마무리 (자정 직후)      ← 매일 반복
  ├─ 03:20  새벽 정산 후 잔여석 반영                    ← 매일 반복
  ├─ 12:00  낮 개인 일정취소                            ← 매일 반복
  ├─ 19:00  퇴근 후 일정취소                            ← 매일 반복
  │                                          └─ 출발 1시간 전: 막판 취소표
  ▼
 이 시각마다 "지금 앱 확인!" 알림 → 메타문이 직접 코레일+ 앱에서 잡기
```

> 이 시간대는 '보장'이 아니라 '확률이 높은 창'입니다. 결제 미완료분 자동취소, 개인 일정
> 변경, 시스템 정산 같은 구조적 이유로 취소·잔여석이 몰리는 구간입니다.

## 3. 설치 (아주 간단 — 추가 설치 패키지 없음)

- **필요한 것: Python 3.10 이상** 하나뿐입니다. 별도 라이브러리 설치가 없습니다.
- Windows에서 [python.org](https://www.python.org) 설치 시 **"Add Python to PATH"** 를 꼭 체크하세요.

```
# 저장소를 받은 폴더에서
python -m ktx_helper guide
```

Windows라면 `run_ktx.bat` 을 **더블클릭**하면 메뉴가 뜹니다.

## 4. 사용법

### 4-1. 설정 화면(웹) — 메모장 없이 클릭으로 입력 (추천)

메모장 편집이 불편하면 **브라우저 설정 화면**을 쓰세요. 날짜는 달력, 시간은 시계로
클릭해 여정을 넣고 **저장**만 누르면 `ktx_config.json` 이 자동으로 만들어집니다.
그 화면에서 텔레그램 테스트와 캘린더(.ics) 내려받기도 됩니다.

```
python -m ktx_helper web
```

- 브라우저가 자동으로 `http://127.0.0.1:8777/` 을 엽니다. (내 PC에서만 열리는 안전한 로컬 주소)
- Windows는 `run_ktx.bat` 더블클릭 → **[1] 설정 화면 열기(웹)** 로도 실행됩니다.
- 다 끝났으면 실행한 검은 창에서 **Ctrl + C** 로 종료하세요.

> JSON 파일을 직접 고치고 싶으면 아래 4-1b 방식을 써도 됩니다.

### 4-1b. (대안) 설정 파일 직접 만들기

`ktx_config.example.json` 을 복사해 `ktx_config.json` 으로 저장한 뒤 값을 고칩니다.
(`run_ktx.bat` 은 파일이 없으면 자동으로 복사하고 메모장을 열어 줍니다.)

```json
{
  "trips": [
    {
      "name": "서울→부산 추석 귀성",
      "dep": "서울",
      "arr": "부산",
      "date": "2026-10-03",
      "time_from": "08:00",
      "time_to": "12:00",
      "train_type": "KTX",
      "passengers": 2
    }
  ],
  "reminders": { "use_default_windows": true, "days_before": 3, "extra_times": [] },
  "notify": {
    "desktop": true,
    "telegram": { "enabled": false, "bot_token": "", "chat_id": "" }
  }
}
```

### 4-2. 명령어

| 명령 | 하는 일 |
|---|---|
| `python -m ktx_helper web` | **브라우저 설정 화면** — 여정을 클릭으로 편집(메모장 대신, 추천) |
| `python -m ktx_helper guide` | 취소표/예약대기 전략 요약 출력 |
| `python -m ktx_helper plan` | 등록한 여정과 **추천 확인 시각** 목록 출력 |
| `python -m ktx_helper ics` | 추천 시각을 **캘린더(.ics)** 로 내보내기 (구글/휴대폰 캘린더에 가져오기) |
| `python -m ktx_helper remind` | **알림 스케줄러 실행** — 창을 켜 두면 시간마다 알림 |
| `python -m ktx_helper setup-telegram` | **텔레그램 봇 설정** — chat_id 자동 감지 후 저장 (5절) |
| `python -m ktx_helper notify-window` | 리마인더 **1회 발송** — 자동화(GitHub Actions/작업 스케줄러)용 (6절) |
| `python -m ktx_helper trains` | 공공데이터로 **열차 시간표 조회** (인증키 필요, 선택) |
| `python -m ktx_helper test` | 알림 채널이 잘 되는지 테스트 |

### 4-3. 가장 추천하는 사용 흐름

1. `ktx_config.json` 에 여정을 적는다.
2. **매진이면 코레일+ 앱에서 '예약대기'를 먼저 건다.** (가장 확실)
3. 예약대기가 안 되면 → `python -m ktx_helper ics` 로 캘린더에 알림을 넣는다.
   (프로그램을 계속 켜 둘 필요 없이 휴대폰이 알아서 울려 줍니다.)
4. 알림이 울리면 코레일+ 앱을 열어 취소표를 직접 잡는다.

## 5. 휴대폰으로 알림 받기 (텔레그램, 강력 추천)

예매는 보통 휴대폰으로 하니, 휴대폰에 문자처럼 바로 뜨는 **텔레그램 알림**이 가장 실용적입니다.
무료이고, 설정은 아래처럼 **1분** 이면 끝납니다.

### 5-1. 텔레그램 봇 만들기 (한 번만)

1. 텔레그램에서 **@BotFather** 를 찾아 `/newbot` → 안내대로 이름을 정하면 **봇 토큰**을 줍니다.
2. 방금 만든 봇과의 대화창을 열고 **아무 메시지**(예: `안녕`)나 보냅니다.

### 5-2. chat_id 자동 감지 + 저장 (명령 한 줄)

```
python -m ktx_helper setup-telegram --bot-token 여기에_봇토큰
```

- 프로그램이 봇에게 온 메시지에서 **chat_id 를 자동으로 찾아** `ktx_config.json` 에 저장하고,
  바로 **테스트 메시지**를 보냅니다. 폰에 알림이 뜨면 성공입니다.
- (봇 토큰만 입력하고 싶으면 인자 없이 `python -m ktx_helper setup-telegram` 실행 → 물어봅니다.)

이제 `remind` 나 아래 자동화가 이 채널로 알림을 보냅니다.

## 6. "자동으로" 문자처럼 받기 — 두 가지 방법

알림이 **자동으로** 오려면, 취소표 시각에 무언가가 대신 실행돼야 합니다. 두 가지 중 고르세요.

### 방법 A. GitHub Actions (PC 안 켜도 됨 · 무료 · 추천) ☁️

PC를 꺼 두어도 GitHub이 정해진 시각(자정 전후·새벽 등)에 대신 실행해 텔레그램으로 보냅니다.

1. 이 저장소 **Settings → Secrets and variables → Actions** 로 갑니다.
2. **Secrets** 에 두 개 추가:
   - `KTX_TG_TOKEN` = 봇 토큰
   - `KTX_TG_CHAT` = chat_id (위 `setup-telegram` 후 `ktx_config.json` 에서 확인)
3. **Variables** 에 (선택) `KTX_UNTIL` = 출발일(예: `2026-10-03`). 이 날이 지나면 자동으로 멈춥니다.
4. `.github/workflows/ktx-remind.yml` 이 **기본 브랜치**에 있으면 예약 실행이 켜집니다.
   지금 바로 시험하려면 **Actions 탭 → KTX 취소표 텔레그램 알림 → Run workflow**(수동 실행).

> 이 방식은 "이 시간대에 앱 확인하세요"라는 **리마인더**를 보냅니다. 좌석 자동조회·자동예매가
> 아니라서 코레일 약관·탐지와 무관하고 안전합니다. 예매는 알림을 받고 메타문이 직접 합니다.

### 방법 B. PC 자동 시작 (컴퓨터를 켜 두는 경우) 💻

- Windows: **`install_autostart_win.bat`** 더블클릭 → `[1] 등록`. 로그인할 때마다 `remind` 가
  백그라운드로 돌며 실시간 알림을 보냅니다. 해제는 같은 파일 `[2] 해제`.
- 수동 실행만 원하면 `python -m ktx_helper remind` (창을 켜 두면 동작).

> PC를 끄면 새벽 알림을 못 받습니다. 그 경우 **방법 A** 나 **캘린더(.ics, 4-2절)** 를 쓰세요.
> 캘린더는 폰이 알아서 울려 줍니다.

> 세 방식(텔레그램 실시간 / GitHub 클라우드 / 캘린더)은 함께 써도 됩니다.

## 7. 공공데이터 열차조회 (선택)

`trains` 명령은 국토교통부 TAGO **열차정보 open API**(공식 공개 데이터)로 해당 여정의
실제 열차편(열차번호·출발/도착시각)을 보여 줍니다. 예매·로그인과 무관하며, 사용자가
data.go.kr 에서 발급받은 **본인 인증키**로만 동작합니다.

1. [공공데이터포털](https://www.data.go.kr) 가입 → "국토교통부 TAGO 열차정보" 활용신청 → 인증키 발급
2. `ktx_config.json` 의 `opendata.service_key` 에 넣는다.
3. `python -m ktx_helper trains` 실행.

> ⚠️ 이 API는 **실시간 잔여석/취소표 여부는 제공하지 않습니다.** 그건 코레일 공식 앱에서
> 직접 확인해야 합니다. 이 도구는 "어떤 열차를 노릴지" 미리 파악하는 용도입니다.

## 8. 이 도구가 하지 않는 것 (설계 원칙)

- ❌ 코레일 로그인 자동화
- ❌ 좌석 자동 예매 / 자동 결제
- ❌ 봇 탐지 우회(무결성 토큰 위조·TLS 위장·IP 우회)
- ❌ 반복 조회로 코레일 서버 두드리기

- ✅ 취소표가 잘 나오는 시간에 **알림**
- ✅ 공식 **예약대기** 안내
- ✅ 공식 **공개 데이터**로 열차편 확인
- ✅ 예매는 **사람이** 공식 앱에서
