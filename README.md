# 보조 모니터(USB 그래픽) 진단 · 복구 도구

스크린샷에서 확인된 문제와 해결 도구입니다.

## 지난번에 무엇이 문제였나?

1. **스크립트가 실행되지 않았습니다.** 오류 메시지
   `'C:\Users\15f001\Desktop\monitor_diag.ps1'이(가) 없습니다`는
   *파일이 그 경로에 없다*는 뜻입니다. 흔한 원인:
   - 파일이 **다운로드 폴더**에 저장됨 (바탕화면이 아님)
   - **OneDrive**가 바탕화면을 옮겨서 실제 경로가 `C:\Users\15f001\OneDrive\바탕 화면`임
   - 메모장으로 저장할 때 확장자가 **`.ps1.txt`** 로 저장됨
2. 수동으로 실행한 `Get-PnpDevice` 결과가 비어 있음 →
   **USB 그래픽 어댑터가 장치 목록에 아예 잡히지 않는 상태**입니다.
3. 백신은 Windows Defender뿐 → 보안 프로그램 차단 가능성은 낮습니다.

## 파일 받을 때 주의 (중요)

- 가장 쉬운 방법: 저장소 첫 화면의 초록색 **[Code] 버튼 > Download ZIP** 으로 한꺼번에 받은 뒤 압축을 풉니다.
- 파일을 하나씩 받을 때는 GitHub의 **다운로드(Download raw file) 버튼**을 사용하세요.
- **파일 내용을 복사해서 메모장에 붙여넣어 저장하지 마세요 — 한글이 모두 깨집니다.**
  (메모장의 기본 저장 방식은 PowerShell 5.1이 한글을 읽는 데 필요한 BOM을 빼고 저장합니다.)

## 사용 방법 (경로 입력이 전혀 필요 없습니다)

1. 아래 4개 파일을 **같은 폴더**에 내려받습니다. (어느 폴더든 상관없음 — 다운로드 폴더 그대로 OK)
   - `run_diag.bat`, `monitor_diag.ps1` — 진단용
   - `run_fix.bat`, `monitor_fix.ps1` — 복구용
2. **`run_fix.bat` 을 더블클릭**합니다. (관리자 권한 팝업이 뜨면 "예")
   - 확장 모드 전환 → 장치 재검색 → 오류 장치 재활성화 → DisplayLink 서비스 재시작을
     자동으로 수행하고, 조치 전/후 활성 모니터 수를 비교해 알려줍니다.
3. 복구가 안 되면 **`run_diag.bat` 을 더블클릭**해서 진단 리포트를 만든 뒤,
   `monitor_diag_report.txt` 내용(자동으로 클립보드에도 복사됨)을
   대화창에 붙여넣어 주세요.

## 복구 스크립트가 하는 일 (모두 안전 · 되돌림 가능)

| 단계 | 조치 | 설명 |
|---|---|---|
| 1 | `DisplaySwitch` 확장 모드 | "PC 화면만" 모드에 잠긴 경우 확장 모드로 전환. Windows 11 22H2 이상은 `/extend` 스위치가 무시되므로 숫자 인수 `3`을 자동 사용. 되돌리기: `Win + P` |
| 2 | `pnputil /scan-devices` | 하드웨어 변경 사항 재검색 (Windows 10 2004 이상). 구버전이면 장치 관리자에서 수동 검색을 안내 |
| 3 | `Enable-PnpDevice` | 비활성화(코드 22)·오류 상태의 USB 그래픽 장치 재활성화. 조치 후 실제 장치 상태를 다시 확인해 결과를 정직하게 보고 |
| 4 | 서비스 재시작 | DisplayLink 서비스가 있으면 재시작 |

파일 삭제, 레지스트리 변경, 보안 설정 변경은 하지 않습니다.
로그는 스크립트 폴더와 바탕화면에 `monitor_fix_log.txt`로 저장됩니다.

## 그래도 안 되면 (하드웨어 점검 순서)

1. USB 케이블을 뽑아 **본체 뒷면 USB 3.0 포트(파란색)** 에 직접 다시 연결 (허브 금지)
2. DisplayLink 계열 어댑터면 [최신 드라이버 설치](https://www.synaptics.com/products/displaylink-graphics/downloads) 후 재부팅
3. `Win + Ctrl + Shift + B` — 그래픽 드라이버 리셋 단축키
4. 어댑터를 **다른 PC**에 연결해 동작 확인 → 다른 PC에서도 안 잡히면 어댑터 고장(교체 필요)
